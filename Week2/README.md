# Week 2 Assignment

Five Java solutions based on the Week 2 assignment PDF.

1. `Problem1_ATMPinLengthValidator.java` — checks PIN string length.
2. `Problem2_WordReversalEncoder.java` — reverses each word while preserving word order.
3. `Problem3_ProductInventoryCSVParser.java` — parses a three-field inventory record.
4. `Problem4_LibraryISBNValidator.java` — normalizes and validates a 13-character code.
5. `Problem5_StopWordWordFrequency.java` — counts words after stop-word filtering and sorts by frequency.

Compile each file separately, then run its class. Each program reads one line from standard input.
