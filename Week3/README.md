# Week 3 — Category C Array Practice

Java solutions for the five problems in the supplied Category C practice PDF.

1. `Problem1_TwoSum.java` — checks pairs with nested loops and returns their indices.
2. `Problem2_BestTimeToBuySellStock.java` — tracks the minimum price and best profit in one pass.
3. `Problem3_ContainsDuplicate.java` — compares each pair using nested loops.
4. `Problem4_MergeSortedArrays.java` — merges two sorted arrays using two pointers.
5. `Problem5_RotateArray.java` — rotates an array to the right using modulo indexing.

Input format: enter the array length, its integer elements, and any required target/value. For merge, enter the first array length and elements, followed by the second array length and elements.
