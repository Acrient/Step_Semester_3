# Week 4 — Category C Array Assignment

Java solutions for the five problems in the supplied Session 4 PDF.

1. `Problem1_ProductOfArrayExceptSelf.java` — prefix and suffix products without division.
2. `Problem2_MaximumSubarray.java` — Kadane's algorithm.
3. `Problem3_ThreeSum.java` — sorting, two pointers, and duplicate skipping.
4. `Problem4_SubarraySumEqualsK.java` — prefix sums with a hash map.
5. `Problem5_FindMinimumRotatedSortedArray.java` — modified binary search.

Compile each Java file separately and run its class. Each program reads the array length followed by its elements; problems 3 and 4 also read their required additional input.
