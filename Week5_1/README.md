# Session 5.1 — Hackathon and Placement Problems

Java solutions based on the uploaded Session 5.1 PDF.

1. `Problem1_HackathonScoreCurveBooster.java` — modifies every score in place.
2. `Problem2_DuplicateTeamNameFinder.java` — finds the first duplicate using nested loops.
3. `Problem3_TopThreePodiumFinder.java` — tracks the top three scores in one pass without sorting.
4. `Problem4_HackathonSeatingGridOptimizer.java` — classifies jagged grid rows using a reusable average helper.
5. `Problem5_PlacementShortlistingRankingEngine.java` — overloads eligibility checks and ranks eligible candidates with Arrays.sort.

For Problem 5, the chosen eligibility rules are CGPA >= 7.5, or CGPA >= 6.5 with coding score >= 60. The composite score is CGPA * 10 + coding score * 0.5.
