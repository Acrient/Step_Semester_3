# Session 5.2 — Fantasy League Problems

Java solutions based on the uploaded Session 5.2 PDF.

1. `Problem1_FantasyTeamScoreMultiplier.java` — doubles the captain's score and multiplies the vice-captain's score by 1.5 in place.
2. `Problem2_DuplicatePlayerPickChecker.java` — detects the first duplicate name using nested loops.
3. `Problem3_TopPerformerTracker.java` — finds minimum, maximum, and spread in one pass.
4. `Problem4_MatchDayGridAnalyzer.java` — uses a row-average helper to classify each match.
5. `Problem5_FantasyLeagueAutoDraftRankingEngine.java` — uses overloaded draftability rules and Comparable to rank eligible players by batting average.

For Problem 5, the chosen rules are: players with at least 10 matches qualify regardless of injury; otherwise, players with at least 5 matches qualify if not injured.
