# Session 6.1 — Student and Campus Management

Java solutions based on the uploaded Session 6.1 PDF.

1. `Problem1_StudentPlacementRecordManagement.java` — placement records with constructors and an array of objects.
2. `Problem2_HostelMessWalletManagement.java` — encapsulated wallet balance, top-ups, safe deductions, and read-only access.
3. `Problem3_CourseCreditManagement.java` — constructor overloading and constructor chaining with `this(...)`.
4. `Problem4_LibraryIDCardManagement.java` — object references and `==` identity comparison.
5. `Problem5_StudentCollegeInformationManagement.java` — shared static college name and student counter.

Each file can be compiled and run independently.
