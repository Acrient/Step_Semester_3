# Session 7.1 — Encapsulation Practice

Java solutions based on the uploaded Category C practice PDF.

1. `Problem1_PiggyBank.java` — private savings, deposit/withdraw actions, and final ID.
2. `Problem2_QuizScorecard.java` — private fixed-size answer array and score-only access.
3. `Problem3_NicknameTag.java` — immutable name tag with final fields.
4. `Problem4_LockerCode.java` — changeable private code with no getter and final locker number.
5. `Problem5_AttendanceSheet.java` — private names, unique attendance count, and name lookup.

Each Java file can be compiled and run independently.
