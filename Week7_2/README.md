# Session 7.2 — Encapsulation and Access Control

Java solutions based on the uploaded Category C assignment PDF.

1. `Problem1_CharacterHealthBar.java` — private health clamped between zero and final maximum health.
2. `Problem2_Playlist.java` — private song storage and defensive-copy getter.
3. `Problem3_PasswordChecker.java` — immutable private password, exposing only strength.
