# Session 8.1 — Polymorphism Coding Questions

Java solutions for the five coding questions in the uploaded PDF.

1. Payment fee calculation: Card 2%, Wallet 1%, Bank Transfer 0%.
2. Library due dates: Book 14 days, DVD 7 days, Magazine 3 days, using 2023-10-26 as the fixed current date.
3. Delivery fees: Standard, Express, and International fee rules.
4. Examination grader: exact matching for MCQ/TF and keyword-based partial credit for essays.
5. Public transport fares: Bus cap, Train rate, and Metro peak factor.

Each problem is in a separate Java file. The solutions use interfaces and implementations to demonstrate polymorphism.
