# Session 8.2 — Polymorphism Assignment Problems

Java solutions for the five assignment problems in the uploaded PDF.

1. Canteen billing: Student 10% discount, Staff 5% discount, Guest ₹10 service charge.
2. Campus parking: Bike hourly rate, Car first/additional hour rates, Truck minimum charge.
3. Hostel electricity: Single ₹8/unit, Shared ₹6/unit split by occupants, AC ₹10/unit plus ₹200.
4. Festival bonus: Full-time 10%, Part-time 5%, Intern fixed ₹2,000.
5. Streaming renewals: Basic 30 days, Standard 90 days, Premium 365 days.

Each problem is in a separate Java file and uses interfaces/implementations to demonstrate polymorphism.
